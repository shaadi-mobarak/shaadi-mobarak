# Shaadi Mobarak — সেটআপ নির্দেশনা (বাংলা)

## ১. ইনস্টল
```
npm install
```

## ২. Environment ফাইল (সিক্রেট কখনো চ্যাটে দেবেন না)
```
cp server/.env.example server/.env
```
`server/.env`-এ শুধু আপনার মেশিনে বসান:
- `MONGODB_URI` — Atlas connection string
- `JWT_SECRET` — কমপক্ষে ৩২ অক্ষরের random secret
- `CLIENT_ORIGIN` — frontend ঠিকানা (যেমন http://localhost:5173)

## ৩. MongoDB সংযোগ পরীক্ষা
```
cd server
npm run test:atlas
```
সফল হলে `OK: MongoDB connection successful` দেখাবে। ব্যর্থ হলে শুধু কারণ দেখাবে, সিক্রেট দেখাবে না।

## ৪. প্রথম Owner অ্যাকাউন্ট
```
cd server
OWNER_EMAIL=আপনার-ইমেইল OWNER_NAME=নাম OWNER_PASSWORD=কমপক্ষে-১০-অক্ষর npm run create-owner
```
এটি শুধু তখনই কাজ করবে যখন কোনো Owner এখনো নেই। এরপর Owner লগইন করে সদস্য অ্যাকাউন্ট Activate করতে পারবে।

## ৫. চালানো ও টেস্ট
```
npm run dev            # frontend 5173, API 5000
npm run build          # frontend production build
cd server && npm run test:integration   # ২৮টি API টেস্ট (Atlas ছাড়া, in-memory MongoDB দিয়ে)
```

## ৬. গুরুত্বপূর্ণ
- প্যাকেজ দাম, রিফান্ড নীতি, OTP প্রোভাইডার ও পেমেন্ট গেটওয়ে মার্চেন্ট অনুমোদন ছাড়া চালু করবেন না। ততদিন পেমেন্ট শুধু ম্যানুয়াল অনুমোদনে চলবে।
- সফল গল্প শুধু ক্লায়েন্টের অনুমোদিত বাস্তব গল্পই প্রকাশ করবেন।
- `.env` কখনো Git-এ কমিট করবেন না।

## ৭. এই ভার্সনে যা আছে (v9, Wedgate ডিজাইন)
- ডিজাইন: Wedgate-র লেআউট ও কালার — মেরুন টপ স্ট্রিপ, মভ/গোলাপি মেনু, হিরো ওয়েডিং-ছবির কোলাজ + Enquire ফর্ম, গোলাপি সেকশন, কালো ফুটার। Wedgate-র লেখা/ছবি/গল্প ব্যবহার করা হয়নি; নিজের বাংলাদেশি ওয়েডিং ছবি ও Shaadi Mobarak-এর কন্টেন্ট ব্যবহার করা হয়েছে।
- পাবলিক পেজ: হোম, পাত্রী, পাত্র, অ্যাডভান্সড সার্চ (বয়স, উচ্চতা, ধর্ম, শিক্ষা, পেশা, জেলা, বৈবাহিক অবস্থা), How It Works, মেম্বারশিপ, সফল গল্প, ব্লগ, FAQ, যোগাযোগ, প্রাইভেসি, টার্মস।
- ড্যাশবোর্ড: মেম্বার, ম্যাচমেকার, অ্যাডমিন/ওনার — ম্যাচমেকার নিজেও বায়োডাটা তৈরি ও ব্যক্তিগত ছবি আপলোড করতে পারে।
- সিস্টেম: শর্টলিস্ট, আগ্রহ, সম্মতি, নোটিফিকেশন, সাপোর্ট টিকিট, অডিট লগ, প্রাইভেট ছবি আপলোড, পেমেন্ট অনুমোদন → মেম্বারশিপ চালু।

## ৮. মোবাইল (ফোন-ব্রাউজার) দিয়ে লাইভ করার ধাপ
1. ফোন ব্রাউজারে হোস্টিং প্রোভাইডারের সাইটে গিয়ে একটি Node.js হোস্টিং + ডোমেইন নিন (অথবা ক্লায়েন্টের আগের হোস্টিং ব্যবহার করুন)।
2. এই ZIP আপলোড/ডিপ্লয় করুন, `server/.env`-এ Atlas `MONGODB_URI`, `JWT_SECRET`, `CLIENT_ORIGIN` (লাইভ ডোমেইন) বসান — কখনো চ্যাটে/পাবলিক জায়গায় নয়।
3. `npm run test:atlas` দিয়ে সংযোগ পরীক্ষা করুন, তারপর `npm run create-owner` দিয়ে প্রথম Owner বানান।
4. লাইভ সাইটে লগইন, টিজার, সার্চ, পেমেন্ট অনুমোদন পরীক্ষা করুন, তারপর ক্লায়েন্টকে ডোমেইন লিংক দিন।
5. HTTPS চালু আছে কিনা, ব্যাকআপ আছে কিনা — হোস্টিং প্যানেলে দেখে নিন।

## ৯. এখনো বাকি আছে (লাইভের আগে লাগবে)
- MongoDB Atlas `MONGODB_URI` ও `JWT_SECRET` — এখনো দেওয়া হয়নি, তাই লাইভ সংযোগ পরীক্ষা করা যায়নি (in-memory টেস্ট পাস করেছে)।
- হোস্টিং/ডোমেইন সিদ্ধান্ত — এখনো নেওয়া হয়নি।
- চূড়ান্ত প্যাকেজ দাম, রিফান্ড নীতি — মালিকের অনুমোদন বাকি; অ্যাডমিন প্যানেল থেকে বদলানো যাবে।
- OTP ডেলিভারি প্রোভাইডার, bKash/Nagad/Rocket/SSLCommerz মার্চেন্ট অনুমোদন — বাকি; ততদিন ম্যানুয়াল পেমেন্ট অনুমোদন।
- মালিকের অনুমোদিত আসল সফল গল্প, ব্লগ/FAQ কন্টেন্ট — বাকি; জায়গা খালি রাখা হয়েছে, বানানো কিছু বসানো হয়নি।
